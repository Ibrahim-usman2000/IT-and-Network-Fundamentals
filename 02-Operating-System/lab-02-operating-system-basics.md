# Lab 02: Operating System Basics

## 1. Overview

This report summarizes foundational operating-system concepts: what an OS does and how a user can navigate a desktop, manage files, review settings, use applications and accounts, and approach updates and security.

**Learning method:** Introductory study and documentation. This report does not claim a separately verified Windows practical session. The repository has dedicated reports for Windows processes, threads, handles, and the Registry, and for Ubuntu Linux; those topics remain in their existing reports.

## 2. Objective

- Explain the general purpose of an operating system.
- Describe common desktop navigation and file-management tasks.
- Identify where system information and settings can be reviewed.
- Understand how applications and user accounts fit into an OS.
- Recognize the role of updates and basic security practices.

## 3. What an Operating System Does

An operating system (OS) provides a working environment between the computer's hardware and the applications and people using it. It starts and coordinates programs, manages access to memory and storage, communicates with devices through drivers, and provides interfaces for users and applications.

Common desktop operating systems include Microsoft Windows, macOS, and Linux distributions such as Ubuntu. Their interfaces differ, but they provide many similar functions: launching applications, organizing files, connecting devices, configuring the system, and managing user access.

## 4. Desktop Interface and Navigation

A graphical user interface (GUI) lets a user interact through visible items such as windows, menus, icons, buttons, and pointers. On a Windows desktop, examples include the Start menu for finding applications and settings, the taskbar for switching between open applications, and File Explorer for navigating storage.

Useful navigation habits include:

- Open one application at a time and identify its title bar, menus, and controls.
- Use the taskbar or application switcher to move between open windows.
- Use search to locate an application or setting when its menu location is unfamiliar.
- Distinguish closing a window from shutting down or restarting the computer.
- Save work before signing out, restarting, or installing updates.

The exact screen layout and menu names can vary by operating-system version and configuration.

## 5. Files and Folders

Files hold information such as documents, images, programs, and settings. Folders organize files into a directory structure. A file's location can be described by its path; a path identifies the drive and folders leading to the file.

Basic file-management tasks include creating a folder, opening and saving a file, renaming or copying an item, and moving it to another folder. Before deleting or replacing anything, check the selected item and its location. Keep personal documents in an appropriate user folder and use clear names so files can be found later.

## 6. Settings and System Information

An operating system provides settings for areas such as display, sound, network connections, devices, accessibility, accounts, and privacy. System-information screens can identify details such as the OS edition and version, processor, installed memory, device name, and activation or update status.

When troubleshooting, record the exact message and relevant system details before changing settings. Prefer documented settings pages and make one change at a time so the result is easier to understand.

## 7. Applications and User Accounts

Applications provide specific functions, such as writing documents, browsing the web, or viewing images. The OS helps launch applications and gives them controlled access to files and devices.

A user account identifies a person's sign-in and determines access to files and system changes. Standard accounts are generally appropriate for everyday work. Administrator privileges allow broader changes and should be used only when needed. Sign out when finished on a shared computer, and protect accounts with strong, unique passwords and any available multi-factor authentication.

## 8. Updates and Security

Operating-system and application updates can fix defects, improve compatibility, and address security vulnerabilities. Check update status through the OS's built-in update settings, use a trusted network, and save work before restarting. Avoid interrupting an update while it is installing.

Basic security practices include:

- Install applications from trusted sources.
- Keep the OS and applications updated.
- Use a screen lock and protect account credentials.
- Be cautious with unexpected links, downloads, and attachments.
- Maintain backups of important files.
- Review prompts before granting administrator access or changing security settings.

## 9. Lessons Learned

- The OS coordinates hardware, applications, files, and user access.
- A GUI provides visible navigation, while settings and search can help locate system controls.
- File paths and careful selection matter when organizing or deleting data.
- System information is useful context when diagnosing a problem.
- Accounts, updates, and safe application choices contribute to system security.
- Concepts and guidance in this report should not be mistaken for evidence of a completed practical exercise.

## 10. Conclusion

Understanding the general role of an operating system provides a foundation for everyday computer use and further study. This introductory report focuses on desktop use and system care. Detailed Windows internals are covered in the separate Windows Processes, Threads, Handles and Registry report, and Linux desktop and command-line practice are documented in the Ubuntu report.
