## 📚 Practical Laboratory Exercises

### 🔧 1. Computer Hardware Disassembly Lab

**Objective:** To identify, examine, and understand the internal components of a computer through a structured disassembly and reassembly exercise.

**Activities performed:**
- Powered down and disconnected the computer safely.
- Removed the computer case side panel.
- Identified and inspected internal hardware components.
- Examined cable connections and removable hardware.
- Observed component placement and motherboard connections.
- Documented findings and observations.
- Reassembled the computer and checked the system.

**Components identified:**
- Motherboard
- Central Processing Unit (CPU)
- Random Access Memory (RAM)
- Power Supply Unit (PSU)
- Solid-State Drive (SSD) and Hard Disk Drive (HDD)
- Cooling system
- Graphics card, where installed
- SATA cables and connectors
- Expansion slots

**Key learning outcomes:**
- Understanding internal PC architecture.
- Identifying major hardware components and their functions.
- Recognizing common connectors and interfaces.
- Applying safe hardware-handling procedures.
- Developing foundational troubleshooting and maintenance skills.

### 🖥️ 2. PC Assembly Lab

**Objective:** To develop an understanding of the procedures involved in assembling a computer system and installing its major hardware components correctly.

**Lab activities and focus areas:**
- Identifying hardware components before assembly.
- Understanding motherboard installation and mounting.
- Learning about RAM and storage installation.
- Understanding CPU installation and cooling requirements.
- Identifying and connecting power cables.
- Connecting storage devices and internal cables.
- Understanding component placement and compatibility.
- Following a systematic PC assembly procedure.
- Understanding post-assembly checks and system verification.

**Lab documentation:** `1.8.1_lab_pc_assembly_manual.html`

**Key learning outcomes:**
- Understanding the sequence of PC assembly.
- Recognizing hardware compatibility requirements.
- Developing knowledge of internal cable connections.
- Understanding basic cable management.
- Learning the importance of systematic testing after assembly.

### ⚙️ 3. Operating System Basics Lab

**Objective:** To explore fundamental operating system concepts by examining Windows processes, threads, handles, system resources, and the Windows Registry.

**Lab activities:**
- Exploring running processes and understanding how applications execute.
- Investigating threads and their relationship to processes.
- Examining handle usage and how operating systems manage system objects.
- Navigating the Windows Registry and identifying its hierarchical structure.
- Observing resource allocation through built-in system monitoring tools.
- Developing an understanding of system stability and operating system management.

**Lab documentation:** `lab-03-os-processes-threads-registry.md`

**Key learning outcomes:**
- Understanding the roles of processes and threads.
- Developing familiarity with Windows Task Manager.
- Understanding the purpose and structure of the Windows Registry.
- Recognizing the importance of system resource monitoring.
- Building foundational knowledge relevant to IT support and cybersecurity.
