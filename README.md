📚 Practical Labs

🔧 1. Computer Hardware Disassembly Lab

Objective: To identify and understand the internal components of a computer through a structured disassembly and reassembly exercise.

Activities performed

- Powered down and disconnected the computer safely.
- Removed the computer's side panel.
- Identified and inspected internal hardware components.
- Examined cables, connectors, and component placement.
- Documented observations.
- Reassembled and tested the computer.

Components identified

- Motherboard
- Central Processing Unit (CPU)
- Random Access Memory (RAM)
- Power Supply Unit (PSU)
- Storage devices (SSD/HDD)
- Cooling system
- Graphics card, if installed
- SATA cables and connectors
- Expansion slots

🖥️ 2. PC Assembly Lab

Objective: To understand the systematic process of assembling a computer and installing its major hardware components.

Lab activities

- Identifying components before assembly.
- Understanding motherboard installation.
- Exploring CPU, cooling, RAM, and storage installation.
- Identifying internal power cables and data connections.
- Understanding component placement and compatibility.
- Following a systematic assembly procedure.
- Checking the system after assembly.

Lab manual: "1.8.1_lab_pc_assembly_manual.html"

⚙️ 3. Operating System Basics Lab

Lab title: Exploring Processes, Threads, Handles, and Windows Registry

Objective: To explore how Windows manages running applications, processes, threads, system objects, and configuration settings.

Tools explored

- Microsoft Sysinternals Process Explorer
- Windows Command Prompt
- Windows Registry Editor ("regedit")

Lab activities

- Examining active processes using Process Explorer.
- Identifying application processes and their relationships.
- Observing process activity while running a "ping" command.
- Exploring parent and child process relationships.
- Examining process threads and their properties.
- Inspecting handles associated with a process.
- Exploring the main Windows Registry hives.
- Locating and examining the Process Explorer "EulaAccepted" registry value.

Key concepts

- Processes: Running instances of programs or applications.
- Threads: Units of execution within a process.
- Handles: References used to access operating-system-managed objects and resources.
- Process relationships: How parent and child processes are associated.
- Windows Registry: A hierarchical database containing Windows and application configuration settings.
- Registry hives: Major sections of the Registry, including "HKEY_CURRENT_USER" and "HKEY_LOCAL_MACHINE".

Learning outcome: Developed a foundational understanding of Windows process management, threads, handles, and Registry configuration as part of my operating-system studies.

Lab documentation: "02-Operating-Systems/lab-03-os-processes-threads-registry.md"
