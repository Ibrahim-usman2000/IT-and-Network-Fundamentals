📚 Practical Labs
🔧 1. Computer Hardware Disassembly Lab
Objective: To identify and understand the internal components of a computer through a structured disassembly and reassembly exercise.

Activities performed:

Powered down and disconnected the computer safely

Removed the side panel

Identified internal components

Detached cables and removable hardware

Inspected component placement and connections

Documented observations

Reassembled and tested the computer

Components identified:

Motherboard

CPU (Processor)

RAM (Memory)

Power Supply Unit (PSU)

Storage Devices (SSD/HDD)

Cooling System

Graphics Card (if installed)

SATA cables and connectors

Expansion slots

🖥️ 2. PC Assembly Lab
Objective: Hands-on laboratory exercise focused on understanding the process of assembling a computer system and correctly installing and connecting its major hardware components.

Lab focus:

Identifying PC components before assembly

Understanding motherboard installation

Installing RAM and storage

Understanding CPU and cooling installation

Connecting power cables

Connecting storage and other internal cables

Understanding component placement and compatibility

Following a systematic PC assembly procedure

Checking the system after assembly

📄 Lab Manual: 1.8.1_lab_pc_assembly_manual.html

⚙️ 3. Operating System Basics Lab
Objective: Hands-on laboratory exercise focused on exploring core operating system concepts, system architecture, and monitoring fundamental OS components.

Lab focus:

Exploring system processes and understanding how applications run

Investigating threads and handle usage within the operating system

Navigating and inspecting the Windows Registry

Observing resource allocation and system stability
