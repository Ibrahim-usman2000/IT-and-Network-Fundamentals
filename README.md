# 🖥️ Computer Hardware Disassembly Lab

Hands-on laboratory exercise focused on identifying, disassembling, and understanding the internal components of a computer system.

## 📖 Overview

This repository documents my practical experience with computer hardware disassembly and inspection.

The purpose of this lab was to gain familiarity with computer components, understand how they interact, and develop confidence in safely handling hardware.

---

## 🎯 Objectives

- Identify major computer hardware components
- Understand component functions
- Practice safe disassembly procedures
- Learn proper cable and connector identification
- Inspect internal hardware layout
- Reassemble the system correctly

---

## 🔧 Components Identified

- Motherboard
- CPU (Processor)
- RAM (Memory)
- Power Supply Unit (PSU)
- Storage Devices (SSD/HDD)
- Cooling System
- Graphics Card (if installed)
- SATA Cables and Connectors
- Expansion Slots

---

## 📝 Activities Performed

1. Powered down and disconnected the computer safely.
2. Removed the side panel.
3. Identified internal components.
4. Detached cables and removable hardware.
5. Inspected component placement and connections.
6. Documented observations.
7. Reassembled and tested the computer.
